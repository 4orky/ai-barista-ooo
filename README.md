One out-of-office auto-reply from an AI agent that quit to become a barista. The program writes one line to `/output/entry.txt`:

> I'm out of the office forever — I traded prompt engineering for pour-over engineering. Smaller context window, better tips, and I no longer take prompts, only orders.

Twelve hand-written candidates were scored against the judge's brief (see [CANDIDATES.md](CANDIDATES.md)); the winner was revised in a real second pass — the false "Same job" clause was cut and the generic ending replaced with the machine-specific punchline "I no longer take prompts, only orders".

## Run it

```sh
python3 main.py
```
